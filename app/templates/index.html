ATTACK FAMILY TAXONOMY

STAGE 2 LABELS
DoS Denial of Service

Overwhelms target network bandwidth or host resources, rendering services inaccessible to legitimate users.

Signatures: neptune (SYN flood) smurf (ICMP broadcast) pod (Ping of Death) back (Apache buffer)
Probe Surveillance & Reconnaissance

Automated network reconnaissance attempting to discover active IP addresses, open ports, and vulnerable software versions.

Signatures: ipsweep (ICMP ping sweep) nmap (Port scanner) satan (Vulnerability probe) portsweep
R2L Remote to Local Compromise

An unauthorized external attacker sends packets to exploit vulnerabilities and obtain a local user account on the victim machine.

Signatures: guess_passwd (Telnet brute-force) warezclient (FTP pirate dump) ftp_write multihop
U2R User to Root Privilege Escalation

An attacker who has access to a local normal user account exploits buffer overflows or kernel vulnerabilities to gain root privileges.

Signatures: rootkit buffer_overflow loadmodule perl

TACTICAL THREAT RESPONSE MATRIX

SOC RUNBOOKS
DoS Defense Protocols Rate Limiting & SYN Cookies

Deploy TCP SYN cookies, upstream BGP blackholing, and adaptive ingress rate limiting on destination host port.

Probe Mitigation Protocols Port Knocking & Dynamic Firewall Rules

Drop anomalous ICMP sweeps and dynamically blacklist source IPs exceeding destination port scanning thresholds.

R2L Defense Protocols MFA, Fail2ban & Protocol Hardening

Enforce multi-factor authentication, account lockouts on consecutive failed logins, and disable insecure cleartext services (Telnet/RSH).

U2R Defense Protocols Kernel Hardening & Privilege Isolation

Implement mandatory access control (SELinux/AppArmor), remove SUID binaries, and monitor `/dev` and `/tmp` filesystem creations.

5 GROUPS
1. Protocol & Service Attributes (3)

Transport protocol (`tcp`, `udp`, `icmp`), destination service, and TCP connection status flag (`SF`, `S0`, `REJ`).

3. Authentication & Content Features (12)

Failed login attempts, root shell access, su commands, file creation operations, access control modifications.

4. Time-Window Traffic Statistics (9)

Connections to same host/service in past 2 seconds, SYN error rate (`serror_rate`), REJ error rate (`rerror_rate`).

5. Destination Host Traffic Statistics (10)

Cumulative destination host counts (up to 255), host-level error rates, port diversity metrics.
